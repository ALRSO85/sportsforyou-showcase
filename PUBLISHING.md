# Publishing Guide

## 1. Create the repository on GitHub

Repository name:

```text
sportsforyou-showcase
```

Suggested visibility:

```text
Public
```

Suggested description:

```text
Public and sanitized technical showcase of SportsForYou: architecture, modules, quality gates, database governance, accessibility and AI-assisted engineering.
```

Suggested topics:

```text
dotnet
software-architecture
distributed-systems
devsecops
sql-server
accessibility
seo
platform-engineering
ai-assisted-development
sports-tech
```

## 2. Publish using Git

From inside the repository folder:

```bash
git init
git branch -M main
git add .
git commit -m "docs: add SportsForYou technical showcase"
git remote add origin https://github.com/ALRSO85/sportsforyou-showcase.git
git push -u origin main
```

## 3. Pin the repository

After publishing, pin this repository to your GitHub profile.

## 4. Add screenshots later

Only add sanitized screenshots. Avoid production data, real users, emails, tokens, private URLs and internal identifiers.
